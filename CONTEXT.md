# Pedroca Skills Framework

The domain glossary for Pedroca's agentic engineering skills, multi-lane Herdr orchestration, and Akashic-governed knowledge workflows.

## Language

### Orchestration & Execution Topology

**Orchestrator**:
The primary coordinating agent session that plans work, interviews the user, manages DAG state, and delegates execution without directly editing application code.
_Avoid_: Main agent, controller, manager, master agent

**Lane**:
A Tier-1 isolated Git worktree and Herdr terminal workspace (`herdr-orchestration`) that executes a bounded workstream on its own branch (`lane/<topic>-<lane>`).
_Avoid_: Worker subagent, implementer subagent, worktree subagent, thread

**Specialist Subagent**:
A Tier-2 in-session agent (`fixer`, `craftsman`, `runner`, `integrator`, `librarian`, `evaluator`, `oracle`, `council`) invoked via `invoke_subagent` to perform a role-bounded task within a single workspace.
_Avoid_: Background agent, helper agent, lane agent

**Skill**:
A versioned directory containing a `SKILL.md` instruction contract and optional deterministic helper scripts that govern a specific engineering activity.
_Avoid_: Plugin, command, prompt template, macro

### Artifacts & State Transfer

**Vault**:
The repository's Akashic-governed documentation directory containing canonical Open Knowledge Format (OKF v0.2) Markdown nodes with typed frontmatter and directed relational edges, validated by `akashic lint`.
_Avoid_: Wiki, docs folder, knowledge base, scratchpad

**Spec**:
A canonical document produced by `/to-spec` that synthesizes problem statement, solution, user stories, implementation decisions, and testing seams for a feature or initiative.
_Avoid_: PRD, design doc, plan file, brief

**Ticket**:
A vertical tracer-bullet work item produced by `/to-tickets` with explicit blocking edges and acceptance criteria, sized for a single execution context or Lane.
_Avoid_: Task, story, slice file, sub-issue

**Kickoff Brief**:
The structured Markdown input contract (`/tmp/handoff-<session>-<lane>.md`) generated by the Orchestrator to define a Lane's objective, allowed file paths, upstream dependencies, and Stage 1 test criteria.
_Avoid_: Handoff prompt, lane spec, worker instructions

**Completion Receipt**:
The structured Markdown output contract (`/tmp/handoff-<session>-<lane>-result.md`) written by a Lane upon finishing execution, declaring `VERDICT`, `WORKFLOW`, `COMMITS`, `FILES_MODIFIED`, `STAGE_1_VERIFICATION`, and `EXPORTED_CONTRACTS`.
_Avoid_: Result log, handoff output, status file

**Handoff**:
A portable session-transition document (`/tmp/handoff-*.md`) created by `/handoff` to transfer conversational state across sessions, directories, or harnesses outside of automated Lane execution.
_Avoid_: Checkpoint, compaction, memory dump

**Verification Gate**:
A deterministic pass/fail checkpoint (`Stage 1` inside a Lane, `Stage 2` on the integration branch, or a `runner` subagent check) that requires an explicit `VERDICT: PASSED` before dependent work proceeds.
_Avoid_: Test step, sanity check, QA phase
